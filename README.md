# موقع الاستبيان للعملاء الجدد — new-client

موقع لوحده، مش مربوط بموقع العملاء ولا بأي موقع تاني.

| الصفحة | الرابط | لمين |
|---|---|---|
| الصفحة الرئيسية | `index.html` | أي حد |
| طلب الاشتراك | `apply.html` | أي حد |
| التقييم الكامل | `assessment.html?t=…` | العميل بعد ما تفعّله |
| المتابعة الأسبوعية | `checkin.html?t=…` | العميل المشترك |
| صفحة العميل | `client.html?t=…` | العميل المشترك |
| **لوحة الكوتش** | `coach.html` | انت بس (بالباسورد) |

الإجابات بتتحفظ في **جوجل شيت بتاعك**، وانت بتشوفها مترتبة في لوحة الكوتش.

---

## الخطوة 1 — جوجل شيت (مرة واحدة)

1. افتح https://sheets.google.com واعمل شيت جديد، وسمّيه مثلًا `New Clients`.
2. من فوق: **Extensions ← Apps Script**.
3. امسح أي كلام موجود، وانسخ كل اللي في ملف `backend/Code.gs` والصقه.
4. في أول الملف، غيّر `CHANGE-ME-Ahmed2026` لباسورد انت تختاره (ده باسورد لوحة الكوتش).
5. اضغط 💾 Save.
6. من القائمة اللي فوق اختار الدالة **setup** واضغط **Run**.
   - هيطلب صلاحيات: Review permissions ← اختار حسابك ← Advanced ← Go to … ← Allow.
7. اضغط **Deploy ← New deployment**:
   - النوع (⚙️): **Web app**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - Deploy ← انسخ الـ **Web app URL**.

## الخطوة 2 — اربط الموقع بالشيت

افتح `assets/config.js` وحط الرابط اللي نسخته بين العلامتين:

```js
apiUrl: "https://script.google.com/macros/s/……/exec",
```

## الخطوة 3 — ارفع على GitHub

1. اعمل repository جديد اسمه `new-client` (Public).
2. ارفع **كل اللي جوه الفولدر** ← Commit changes.
3. Settings ← Pages ← Branch: `main` / `(root)` ← Save.
4. بعد دقيقتين:
   - رابط العملاء: `https://coachahmedmaher-hub.github.io/new-client/`
   - لوحة الكوتش: `https://coachahmedmaher-hub.github.io/new-client/coach.html`

---

## الشغل اليومي

1. العميل بيقدّم ← بيظهرلك في لوحة الكوتش (وفي تاب Applications في الشيت).
2. تفتح العميل ← تكلمه ← لما تقبله وتتأكد من الدفع: **فعّل التقييم وابعت الرابط** ← زرار واتساب بيبعتله رابطه الشخصي.
3. العميل بيملا التقييم ← بيظهرلك الملخص الذكي + الحاجات اللي لازم تراجعها + كل الإجابات.
4. تغيّر الحالة لـ **مشترك**، وتحدد مدة الاشتراك وتاريخ البداية (النهاية بتتحسب لوحدها).
5. كل أسبوع العميل بيبعت متابعته من نفس الرابط ← بتشوف الرسوم البيانية.

## لو غيّرت ملف Code.gs بعدين

Deploy ← **Manage deployments** ← ✏️ ← Version: **New version** ← Deploy (الرابط بيفضل زي ما هو).

## تغيير الباسورد

غيّر `COACH_PASSWORD` في Code.gs ← Save ← شغّل **setup** تاني.
